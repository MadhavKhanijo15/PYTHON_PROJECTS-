An IPv4 address is a numeric identifier that a device uses to communicate on the internet, akin to a postal address in the real world, typically formatted in dot-decimal notation as #.#.#.#. But each # should be a number between 0 and 255, inclusive.  

This program expects an IPv4 address as input as a str and then returns True or False, respectively, if that input is a valid IPv4 address or not.  
This program is based on Regular expressions and uses the module - RegEx or re
