This is a program that expects exactly one command-line argument, the name (or path) of a CSV file, and outputs a table formatted as ASCII art using tabulate, a package on PyPI at pypi.org/project/tabulate. Formated the table using the library’s grid format. If the user does not specify exactly one command-line argument, or if the specified file’s name does not end in '.csv', or if the specified file does not exist, the program instead exits via sys.exit.
Of course, a CSV file isn’t the most customer-friendly format to look at. Prettier might be a table, formatted as ASCII art, like this program does . There are two csv files attached within this folder , use them to try the code .
This program uses tabulate library , make sure to install it by passing the following command in terminal - pip install tabulate
